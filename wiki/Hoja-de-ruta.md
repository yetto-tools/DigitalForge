# Hoja de ruta

DigitalForge se encuentra en etapa pre-alpha. Esta página resume las áreas que
el repositorio identifica como futuras o incompletas; no representa fechas ni
compromisos de publicación.

## Pendientes conocidos

- Mostrar en la interfaz el reporte completo de compatibilidad.
- Conservar metadata JSON desconocida al volver a guardar.
- Mejorar la selección de documentos para subcircuitos y actualizar sus pines
  cuando cambie el documento referenciado.
- Soportar buses reales de múltiples bits.
- Completar la experiencia y validación de importación desde Logisim.

## Ecosistema de componentes

- Diseñar e implementar el lenguaje DFML.
- Crear el compilador o formato compilado DFMC.
- Añadir bibliotecas externas DFLIB.
- Incorporar dependencias, alias, migraciones y ciclo de vida de componentes.

## Fuera del modelo actual

La simulación analógica de voltaje, corriente y resistencia requeriría un motor
distinto del simulador lógico discreto actual y no está implementada.

Para comprobar el estado real de una función, consulta primero el
[README](https://github.com/yetto-tools/DigitalForge/blob/main/README.md),
el [registro de cambios](https://github.com/yetto-tools/DigitalForge/blob/main/CHANGELOG.md)
y los [issues](https://github.com/yetto-tools/DigitalForge/issues).
