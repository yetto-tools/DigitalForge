# Instalación

## Windows

1. Abre la página de
   [Releases](https://github.com/yetto-tools/DigitalForge/releases).
2. Descarga `DigitalForge-Setup-<versión>.exe`.
3. Ejecuta el instalador y sigue el asistente.

## Linux

1. Descarga `DigitalForge-<versión>-x86_64.AppImage` desde
   [Releases](https://github.com/yetto-tools/DigitalForge/releases).
2. Concede permiso de ejecución:

```bash
chmod +x DigitalForge-<versión>-x86_64.AppImage
```

3. Inicia la aplicación:

```bash
./DigitalForge-<versión>-x86_64.AppImage
```

## Actualizaciones

DigitalForge comprueba al arrancar si existe una versión más reciente. También
puedes ejecutar la comprobación manual desde **Ayuda → Buscar actualizaciones**.

## Compilar desde el código fuente

Para compilar DigitalForge en lugar de instalar un binario, consulta
[Desarrollo](Desarrollo).
